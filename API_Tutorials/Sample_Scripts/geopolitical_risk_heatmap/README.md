# Geopolitical Risk Heatmap

Build a country-by-week heatmap for geopolitical risk narratives using [Bigdata.com](https://bigdata.com) Volume.

## APIs

- `POST /v1/search/volume`

## Script

- `geopolitical_heatmap.py`

## Run

```bash
export BIGDATA_API_KEY=your_api_key_here
uv run python geopolitical_heatmap.py
```
