# Competitor Narrative Compare (Nvidia vs AMD)

Compare coverage intensity and top headlines for competing entities using [Bigdata.com](https://bigdata.com) Search.

## APIs

- `POST /v1/knowledge-graph/companies`
- `POST /v1/search`

## Script

- `nvidia_vs_amd.py`

## Run

```bash
export BIGDATA_API_KEY=your_api_key_here
uv run python nvidia_vs_amd.py
```
