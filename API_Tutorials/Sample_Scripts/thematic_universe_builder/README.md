# Thematic Universe Builder (Quantum)

Discover top companies in a theme by co-mention volume and resolve metadata via [Bigdata.com](https://bigdata.com).

## APIs

- `POST /v1/search/co-mentions/entities`
- `POST /v1/knowledge-graph/entities/id`

## Script

- `quantum_computing_comentions.py`

## Run

```bash
export BIGDATA_API_KEY=your_api_key_here
uv run python quantum_computing_comentions.py
```
